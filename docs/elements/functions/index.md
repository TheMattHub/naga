Function names are case sensitive. The functions borrowed from Python are lower case: `abs`, `ceil`, `exp`, `float`, `floor`, `int`, `log`, `log10`, `max`, `min`, `round` and `sqrt`. Every other function is upper case, such as `IF`, `TABLE` or `EXPO`. `max(1, 2)` works, while `MAX(1, 2)` stops with an error that says the function is unknown. The one exception is `SQRT`, which exists in both spellings.
