# Citing Naga

If Naga contributed to a paper, a thesis or a report, please cite it. The repository carries a `CITATION.cff` file, which GitHub turns into a "Cite this repository" button and which reference managers such as Zotero can read.

```yaml
--8<-- "CITATION.cff"
```

Name the version you ran, which `pip show nagasim` prints, because results can change between releases. Together with the seed and the model file, the version is what lets a reader repeat a run.
